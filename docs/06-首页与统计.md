### 1.1 `screen` — 大屏数据（最有用）

**请求**：`{}`

**返回 16 个字段**：

| 字段 | 说明 |
|---|---|
| `project_name` | 项目名 |
| `user_count` | 用户总数 |
| `user_register` | 注册用户 |
| `user_month_active` | 月活 |
| `user_day_active` | 日活 |
| `good_detail_count` | 商品数 |
| `active_line_date` / `active_line_value` | 活跃折线（日期 / 值） |
| `order_line_date` / `order_line_value` | 订单折线 |
| `today_order_user` | 今日下单用户 |
| `today_order_amount` | 今日订单额 |
| `today_order_count` | 今日订单数 |
| `order_last` | 最近订单 |
| `good_rank` | 商品排行 |
| `day` | 日期 |

```python
r = post("/admin/index/screen", {})
d = r["data"]
print(f"用户 {d['user_count']} / 日活 {d['user_day_active']} / 今日订单 {d['today_order_count']}")
```

### 1.2 `getRegions` — 省市区（35 个）

```python
r = post("/admin/index/getRegions", {})
# 字段：region_id, region_name, region_pid, region_level, children
```

结构：

```
省（level=1）
  └─ 市（level=2）
      └─ 区（level=3）
```

**用途**：订单收货地址、门店地区选择。

```python
def flatten_regions(regions, out=None):
    out = out if out is not None else []
    for r in regions:
        out.append({"id": r["region_id"], "name": r["region_name"], "level": r["region_level"]})
        flatten_regions(r.get("children", []), out)
    return out
```

### 1.4 `logs` — 操作日志

**请求**：`{"page": 1, "limit": 20}`

**字段**：`log_id`, `admin_id`, `api_url`, `request_ip`, `request_method`, `request_param`

> 💡 **调试利器**：可以反查自己刚才调了什么接口、传了什么参数。

```python
r = post("/admin/index/logs", {"page": 1, "limit": 10})
for log in r["data"]:
    print(log["api_url"], log["request_method"], str(log["request_param"])[:80])
```

## 二、统计 `statistics`（10 个接口）

| 接口 | 说明 | 状态 | 返回 |
|---|---|---|---|
| `statistics/orderStat` | 订单统计 | ✅ | dict（8 键） |
| `statistics/orderStatExport` | 订单统计导出 | ✏️ | — |
| `statistics/goodsSell` | 商品销量 | ✅ | dict（2 键） |
| `statistics/goodsCateSell` | 分类销量 | ✅ | dict（3 键） |
| `statistics/grossProfit` | 毛利 | ✅ | — |
| `statistics/financeDay` | 财务日报 | ✅ | dict（2 键） |
| `statistics/sourceFinance` | 来源财务 | ✅ | — |
| `statistics/conversion` | 转化 | ✅ | dict（2 键） |
| `statistics/survey` | 概览 | ✅ | dict（8 键） |
| `statistics/orderGoodsStats` | 订单商品统计 | ✅ | — |

### 2.1 `orderStat` — 订单统计

**返回字段（8 个）**：

```
total, lists, searchForm, mallArr, financeArr, userFinanceArr, platformTypeArr, sql
```

| 字段 | 说明 |
|---|---|
| `total` | 汇总数值 |
| `lists` | 明细列表 |
| `searchForm` | 当前搜索条件（回显） |
| `mallArr` | 商城下拉选项 |
| `financeArr` | 财务类型选项 |
| `userFinanceArr` | 用户财务选项 |
| `platformTypeArr` | 平台类型选项 |
| `sql` | 调试用 SQL（可能为空） |

> 💡 `searchForm` / `*Arr` 这类字段可以用来**反查筛选参数有哪些**！

### 2.2 `survey` — 概览（8 键）

综合概览数据（用户、订单、销售额等核心指标）。

### 2.3 `goodsCateSell` — 分类销量（3 键）

按分类维度统计销量，可用于验证分类改造效果。

## 三、实战：生成运营日报

```python
def daily_report():
    screen = post("/admin/index/screen", {})["data"]
    order  = post("/admin/statistics/orderStat", {})["data"]
    survey = post("/admin/statistics/survey", {})["data"]

    print("=== 运营日报 ===")
    print(f"用户总数 : {screen.get('user_count')}")
    print(f"日活     : {screen.get('user_day_active')}")
    print(f"今日订单 : {screen.get('today_order_count')} 单")
    print(f"今日销售额: {screen.get('today_order_amount')}")
    print(f"商品总数 : {screen.get('good_detail_count')}")
    print(f"订单统计 : {order.get('total')}")
    return screen, order, survey
```
