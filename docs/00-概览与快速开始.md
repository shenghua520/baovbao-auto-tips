## 5 分钟上手

### 第一步：准备鉴权信息

从项目里拿到 `auth.json`（或登录后自己保存）：

```json
{
  "admin_id": 3,
  "sid": 303,
  "token": "你的token"
}
```

> ⚠️ 本文档中 token 一律用 `<TOKEN>` 占位。

### 第二步：写通用客户端

```python
import requests, json

BASE = "https://mall.baovbao.com"
auth = json.load(open("auth.json"))

HEADERS = {
    "uid": str(auth["admin_id"]),
    "sid": str(auth["sid"]),
    "token": auth["token"],
    "Content-Type": "application/json;charset=UTF-8",
    "User-Agent": "Mozilla/5.0",
    "Origin": BASE,
    "Referer": BASE + "/admin/index.html",
}

def post(path, payload=None):
    """所有接口统一：POST + JSON body + Header 鉴权"""
    r = requests.post(BASE + path, json=payload or {}, headers=HEADERS, timeout=30)
    return r.json()
```

### 第三步：调一个接口试试

```python
# 拉商品分类（cate_type=1）
r = post("/admin/goodsCate/lists", {"cate_type": 1, "page": 1, "limit": 500})
print(r["code"])        # 0 = 成功
print(len(r["data"]))   # 分类数量
for c in r["data"]:
    print(c["cate_id"], c["cate_name"], "二级数:", len(c.get("children", [])))
```

## 通用约定（必须遵守）

### 1. 全部 POST

即使是"查询"接口（lists / detail）也用 **POST**。GET 请求会失败。

### 2. Content-Type 必须是 JSON

```
Content-Type: application/json;charset=UTF-8
```

> 🔴 **含嵌套数组的接口（`good/edit`）用 form-data 会报 `品牌参数错误`**。
> 嵌套数组如 `good_cate=[[1, 1604, 2191]]`、`good_brand=[[2147, 2148]]` 必须走 JSON。

### 3. 鉴权走 Header，不是 Body

```python
# ✅ 正确
headers = {"uid": "<UID>", "sid": "303", "token": "<TOKEN>"}
requests.post(url, json=payload, headers=headers)

# ❌ 错误：把 token 放 body 里
requests.post(url, json={"token": "xxx", ...})
```

### 4. 响应统一格式

```json
{
  "code": 0,
  "msg": "请求成功, 操作成功",
  "data": [],
  "time": "2026-09-23 12:13:57",
  "duration": 0.0367
}
```

| 字段 | 说明 |
|---|---|
| `code` | `0` 成功，其他失败 |
| `msg` | 提示信息（失败时是排查关键） |
| `data` | 业务数据（可能是 list / dict / null） |
| `time` | 服务器时间 |
| `duration` | 处理耗时（秒） |

### 5. 分页

大部分列表接口接受：

```json
{"page": 1, "limit": 100}
```

`limit` 建议一次拉全（如 500），减少请求次数。

## 高频陷阱速查

| 陷阱 | 现象 | 解决 |
|---|---|---|
| **分类/品牌接口漏 `period`** | `1002 上架的商城 必须为正整数~` | 必须带 `period: 72` |
| **分类名超过 6 字符** | `分类名称 最大长度为: 6位` | 缩写（如"谷物/早餐麦片"→"早餐麦片"） |
| **`good/edit` 用 form-data** | `品牌参数错误` | 改用 JSON body |
| **`good/lists` 的 `good_source` 传 "all"** | 拉不到数据 | 循环查 `1`（自营）和 `3`（供应链） |
| **删除分类时下面有商品** | `10501` 删除失败 | 先迁移商品，再删分类 |
| **图片 URL 被剥域名** | 商品图片全失效 | 见 **08 · 图片与文件规范** |
