```python

```

## 七、实战：按手机号找用户

```python
def find_user(phone):
    page = 1
    while True:
        r = post("/admin/user/lists", {"page": page, "limit": 100})
        data = r.get("data") or []
        if not data:
            return None
        for u in data:
            if u.get("phone") == phone:
                return u
        if len(data) < 100:
            return None
        page += 1
        time.sleep(0.08)
```

> 💡 `user/lists` 实测不直接支持 `phone` 过滤参数（传了无效），需拉回本地筛选。若数据量大建议用 `good_field` 类参数试探（各模块搜索参数不统一）。
