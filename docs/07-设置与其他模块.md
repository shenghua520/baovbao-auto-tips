### 1.1 `fieldList` — 字段列表（103 字段）

```python
r = post("/admin/setting/fieldList", {})
# 返回 dict，103 个键
```

> 💡 这是**自定义字段配置**，返回 103 个字段定义。可用于了解系统支持哪些扩展字段。

### 1.2 `pay` / `third` / `pagestyle` 等

实测返回**空数组**（本商城未配置），但接口本身可用（code=0）。
