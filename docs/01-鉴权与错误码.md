# 01 · 鉴权与错误码

## 一、鉴权

### 1.1 鉴权方式

后台是 **Vue SPA**，登录后把凭证放 **HTTP Header**（不是 cookie、不是 body）。

| Header | 必填 | 示例 | 说明 |
|---|---|---|---|
| `uid` | ✅ | `3` | 管理员 ID（`admin_id`） |
| `sid` | ✅ | `303` | 会话 ID |
| `token` | ✅ | `<TOKEN>` | 令牌（40 位，ghp_ 或纯 hex） |
| `Content-Type` | ✅ | `application/json;charset=UTF-8` | **必须** |
| `Origin` | 建议 | `https://mall.baovbao.com` | 部分接口校验 |
| `Referer` | 建议 | `https://mall.baovbao.com/admin/index.html` | 部分接口校验 |
| `User-Agent` | 建议 | `Mozilla/5.0` | 避免被拦 |

### 1.2 完整 Header 示例

```python
HEADERS = {
    "uid": "<UID>",
    "sid": "303",
    "token": "<TOKEN>",
    "Content-Type": "application/json;charset=UTF-8",
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)",
    "Origin": "https://mall.baovbao.com",
    "Referer": "https://mall.baovbao.com/admin/index.html",
}
```

### 1.3 Token 从哪来

**方式 A：复用已有 token**（最快）

项目里若已存 `auth.json`，直接读：

```python
auth = json.load(open("auth.json"))
# {"admin_id": 3, "sid": 303, "token": "..."}
```

> 实测 token 有较长有效期（9/21 签发的 9/23 仍可用）。

**方式 B：走登录接口**（见 02 或下面）

## 二、登录流程

### 2.1 `POST /admin/Login/captcha` — 取验证码

**请求**：`{}`（空 body 即可）

**响应**：

```json
{
  "code": 0,
  "msg": "请求成功",
  "data": {
    "captcha": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAGQAAAAo..."
  }
}
```

> 🔑 **验证码是 base64 PNG 图片**，不是文字！需要 OCR 识别出算式（如 `5+9`）并算出答案（`14`）。

**Python 处理**：

```python
import base64
r = post("/admin/Login/captcha")
b64 = r["data"]["captcha"].split(",")[1]     # 去掉 data:image/png;base64,
open("captcha.png", "wb").write(base64.b64decode(b64))
# → OCR 识别得到 "5+9" → 答案 14
```

### 2.2 `POST /admin/Login/adminLogin` — 账号登录

**请求参数**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `account` | string | ✅ | 账号（如手机号） |
| `password` | string | ✅ | 密码 |
| `captcha` | string | ✅ | 验证码答案（纯数字字符串，如 `"14"`） |

**响应（成功）**：

```json
{
  "code": 0,
  "data": {
    "sid": 303,
    "admin_id": 3,
    "nick_name": "生花",
    "token": "<TOKEN>"
  }
}
```

**响应（失败）**：

```json
{"code": 1000, "msg": "请求错误, 验证码错误~"}
{"code": 1000, "msg": "请求错误, 请输入验证码~"}
```

## 三、错误码全表

| code | 含义 | 常见触发 | 排查 / 解决 |
|---|---|---|---|
| **0** | ✅ 成功 | — | — |
| **1** | 通用错误 | 见 `msg` | 按 msg 处理 |
| **1000** | 请求错误（业务） | 验证码错误、账号密码错 | 重新取验证码 |
| **1002** | **参数错误** | 缺必填字段 | **最常见**。分类/品牌接口通常是漏 `period` |
| **1003** | 参数相关 | 见 msg | — |
| **1004** | 参数相关 | 见 msg | — |
| **1014** | **权限不足** | `账号权限不足,请联系客服人员, /admin/xxx` | 当前账号无该模块权限，换号或申请 |
| **10501** | 业务限制 | `操作失败, 该分类下有上架中的商品` | 先迁移/下架商品再删 |

### 3.1 1002 详解（最高频）

**分类 / 品牌接口** 报 1002：

```json
{"code":1002,"msg":"上架的商城 必须为正整数~"}
```

→ **补 `period: 72`**（上架期，单位天，正整数）。

```python
# ❌ 缺 period
{"cate_name": "铅笔", "cate_pid": 1604, "cate_type": 1, "sort": 100}

# ✅ 正确
{"cate_name": "铅笔", "cate_pid": 1604, "cate_type": 1,
 "period": 72, "sort": 100, "state": 1, "is_display": 1, "shop_type": 1}
```

**其他 1002**：

| msg | 原因 | 解决 |
|---|---|---|
| `分类名称 最大长度为: 6位` | 名称超长 | 缩写到 ≤6 字符 |
| `品牌参数错误` | `good/edit` 用了 form-data | 改用 JSON body |
| `category参数 不能为空~` | `index/uploadImg` 缺参 | 传 `category` |

### 3.2 1014 权限不足

```json
{"code":1014,"msg":"账号权限不足,请联系客服人员, /admin/Index/index"}
```

说明该接口需要更高权限。实测中 `/admin/Index/index`（注意大写 I）会报 1014，而 `/admin/index/index`（小写 i）正常 —— **注意大小写**。

### 3.3 10501 删除限制

```json
{"code":10501,"msg":"操作失败, 该分类下有上架中的商品"}
```

**解决顺序**：

```
1. 建新分类
2. 迁移商品到新分类（good/edit 改 good_cate）
3. 确认旧分类下无商品（good/lists 全量扫描 source 1 和 3）
4. 删除旧分类
```

## 四、调试技巧

### 4.1 先看 code，再看 msg

```python
r = post("/admin/goodsCate/add", payload)
if r.get("code") != 0:
    print("失败:", r.get("code"), r.get("msg"))
else:
    print("成功")
```

### 4.2 用 `/admin/index/logs` 看操作日志

```python
r = post("/admin/index/logs", {"page": 1, "limit": 20})
# 返回：log_id / admin_id / api_url / request_ip / request_method / request_param
```

可以反查自己刚才调了什么、参数是什么。

### 4.3 接口大小写敏感

后台存在 `index` 和 `Index` 两种路径，权限不同。**照抄前端 JS 里的大小写**（从 `API_CATALOG.md` 复制最稳）。

## 五、安全建议

| 项 | 建议 |
|---|---|
| Token 存储 | 放项目外 / 环境变量，**不要提交到 Git** |
| 上传文档/代码前 | 把 token 替换为 `<TOKEN>` 占位符 |
| 写操作接口 | 先 dry-run，确认无误再 EXEC |
| 批量请求 | 加 `time.sleep(0.08~0.15)` 节流，别并发（后台会 502） |
